# 🌤️ Mini-Station-Météo

Une petite application web qui affiche la météo actuelle d’une ville saisie par l’utilisateur, en utilisant les APIs **Nominatim (OpenStreetMap)** et **Open-Meteo**.

## 🚀 Fonctionnalités

- Recherche de ville par nom
- Affichage des coordonnées GPS (latitude / longitude)
- Affichage de la température, vitesse du vent et code météo
- Interface responsive et esthétique

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (ES6+, modules)
- APIs :
  - [Nominatim (OpenStreetMap)](https://nominatim.openstreetmap.org/)
  - [Open-Meteo](https://open-meteo.com/)
